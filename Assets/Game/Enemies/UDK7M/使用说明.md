# UDK7M：模型、动画与共用工作台

## 打开工作台

1. 在 Project 选中 `Actions/UDK7MActions.asset`。
2. Inspector 点「打开共用动作工作台」。也可以选中后打开 `Tools > Game Actions > Animation Workbench 动画工作台`。
3. 左侧选择动作，拖时间轴预览。速度、起止帧、事件、Hitbox、位移轨道、取消和混合设置沿用拳套/共鸣者的同一套工具。
4. 选择「衔接」预览两个动作的混合。已准备下砸、冲刺的准备 → 维持 → 收势 → Idle，以及 Idle ↔ 三连下砸的可编辑规则。

`Preview Focus` 与 `Preview Distance` 在动作配置的 Inspector 中控制大型机械的预览取景；滚轮依然缩放。现有其他配置默认值为 0，取景行为不变。

## 动作对应

| 工作台 ID | Blender 动作 | 帧范围（30 FPS，导入后从 0 开始） |
|---|---|---|
| Idle | UDK7M_Idle | 0–30，循环 |
| TripleSlam | 三连下砸 | 0–90 |
| SlamPrepare | 下砸准备 | 0–15 |
| SlamHold | 下砸维持 | 0–15，循环 |
| SlamRecover | 下砸收势 | 0–30 |
| ChargePrepare | 冲刺准备 | 0–15 |
| ChargeHold | 冲刺维持 | 0–15，循环 |
| ChargeRecover | 冲刺收势 | 0–18 |
| OriginalDemo | 旧版全部控制骨示例 | 原 1–144 → 0–143 |

攻击标记已启用，但没有替你猜测伤害帧：Hitbox 与声音/特效事件初始为空。添加 Hitbox 后可选 CustomBone，填写 `DrillRoll`（钻芯）、`Tool`（钻具）、`Boom`（大臂）或 `Forearm`（前臂），然后调整局部位置和尺寸。尺寸单位为米。

## 放入场景

拖入 `Prefabs/UDK7M.prefab`。根物体保持单位缩放，内部 Visual 保留 FBX 的坐标转换。Generic Animator 默认播放 Idle；参数 `Play_TripleSlam` 等 Trigger 可预览各动作。可编辑 Clip 在 `Animations/Clips`，源 FBX 在 `Animations/Source`。

工作台配置不会自行生成敌人 AI 或伤害逻辑。后续行为脚本可复用 Visual 上的 `ActionRunner` / `ActionMotionPlayer`，调用 Play 并按游戏逻辑 Advance；接入现有命中查询器后再消费自己定义的窗口和事件。工作台衔接规则与 Animator 的 Trigger 预览控制器是两个入口；正式动作系统应读取 ActionSet。

根骨骼的原动画位移保留在 Clip，轨道同时记录了逐帧位移。需要由 AI 控制移动时，使用轨道 RootDelta 并剥离模型的同一份水平位移，避免应用两次。

## 资产与原文件

模型约 **38,289 个三角面**，主体/履带/软管三组蒙皮。履带节点、软管 Hook、机械臂 IK 均已转成普通 FK 骨骼动画，Unity 无需运行 Blender 驱动器。

原始 Blender 绑定和关键帧未修改。中转与验证文件在 Assets 外的目录 `AssetStaging/UDK7M`（不参与游戏打包）；可用转换版是 `UDK7M_Portable_Corrected.blend`。日后继续 K 动画仍使用你原来的 SimpleRig 工程。

材质采用现有 Drone atlas shader，主图 4K、履带 1K、软管 512；锈蚀、掉漆、污渍已烘焙，保留共享微表面法线。没有将主图升级成 8K。

查看 `Assets/Game/Scene/UDK7MAnimationReview.unity` 可单独检查外观和动画。

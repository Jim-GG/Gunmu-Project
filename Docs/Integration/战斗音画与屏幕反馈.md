# 战斗音画与屏幕反馈

本轮继续使用原版 GauntletCombat、原版蓄力时钟和逐帧 Hitbox。关卡移动/动量解谜及 UDK7M 三阶段规则不变。

| --- | --- | --- |

击退写入通用 `GauntletActions` 和 UDK7M 实际玩家引用的 `ParkourGauntletActions`。墙体仍限制位移。卡肉不修改全局时间，不冻结布娃娃；活体受击动作和玩家挥拳暂停，尸体继续真实物理飞行。

- 三级出拳使用“三级蓄力出拳.mp3”，与原有蓄力录音分开，释放出拳时播放。
- 命中共鸣者随机使用“打击音效-01”至“-10”；声音通过实际有效 Hitbox 的伤害/可见性门槛，未命中或隔墙不会播放肉体命中声。
- 混凝土拳击使用 `Impact_Blunt_Large_V5_Stone_02.mp3`。
- 格挡按后续反馈恢复原版 `ObjectAudio.ParryImpact`，`guardImpact` 留空。新导入的格挡文件保留，不使用它覆盖原版。
- 主角真实扣血播放现有七个受击声音的变体，二维本地播放、默认音量 0.28，带 0.25 秒限流。完美格挡不播放受伤声。
- 共鸣者在 `Screaming` 状态播放“共鸣者吼叫.mp3”，死亡立刻停止；同一演员有重播间隔，声音随距离衰减。
- 布娃娃各骨骼只上报碰撞，整具尸体共用 body fall 音库、速度门槛与声音限流，不为每块骨骼创建声音源。
- 拳套血雾改为原地 single burst 4–5 粒紫色烟雾，使用现有 8×8 图集逐帧动画。命中共鸣者不再额外喷晶体碎片。

## UDK7M 与落物

撞晶柱原先的长时间向内聚集圈改为默认 0.6 秒模型电流覆盖，以及世界色散能量冲击和附近屏幕脉冲。使用独立覆层，原模型材质不改；二阶段原有蓄能等待和玩法规则保留。

过载等待期间原来每 0.25 秒调用的 `CombatEffect.Resonance` 会回退到青蓝色方块粒子池，现已移除。撞柱开始及等待结束进入二阶段时各播放一次短促色散冲击波，等待期间不再生成该粒子。

落石复用新增四块 Blender mesh；普通水晶使用 Fractured / Squat，中央水晶用 Squat。最大边长默认分别为 2.1 / 1.3 / 3.1 米。落石按最大共面面积把大面朝下，叠加随机水平朝向和最多 6° 小倾斜，只做慢速水平旋转。保留场地原有落石材质。

显示与动态凸包共用相同 mesh 及完整变换，旧方盒禁用；水晶牵引也引用实际凸包。警示圈覆盖所有旋转的包围范围并加余量，普通落石默认约 4.26 米直径；使用独立半透明材质，无碰撞。凸包会填平凹陷，这是动态刚体的形状约束。

## 屏幕信号系统

`ScreenEffectSignals.Emit` 接受事件、世界点、强度、影响范围和可选接收玩家。`ScreenEffectEmitter` 可由 Inspector 的 UnityEvent 直接调用。每个相机持有自己的材质实例与有上限的脉冲队列。

- 高速：10–28 米/秒渐增径向模糊，减速恢复。
- 不同力量命中：四档短促径向模糊与轻微快速推拉。
- 爆炸、重型砸击和落物冲击：附近的短脉冲，自动衰减。
- 共鸣爆炸：径向模糊、色散、紫色透明流动噪波边缘。
- 共鸣者吼叫：18 米内的轻量径向模糊与色散，随距离减弱。
- 蓄力：三档渐增暗角，最大额外强度 0.12。
- 受伤：前后来源轻微抬头，左侧来源右上，右侧来源左上。
- 低于 30% 血量：透明红色不规则屏幕边缘，恢复后消失。

使用 Unity 6.3 原生 Full Screen Pass，After Post Processing + Fetch Color Buffer。只给现有 PC/Mobile Renderer 追加 Feature，保留原有 SSAO、Decal 和用户 Volume。径向模糊使用 8/12/16 个固定采样档位；色散、暗角、噪波可独立控制。无效果时跳过 Pass，不使用全局 Shader 参数。

按实际试玩反馈，提高了径向混合与采样范围：轻拳 0.38/0.075，一蓄 0.50/0.10，二蓄 0.72/0.14，三蓄 0.90/0.18；吼叫 0.55/0.12，普通爆炸 0.90/0.19，共鸣爆炸 0.95/0.18。高速最大混合 0.75、范围 0.14。对应事件的色散也增强，持续时间与清晰中心保留；暗角和镜头抖动仍维持轻量。

# 材质质感重做规范 V2

V2 已实现，本文保留最初规划。用户反馈后，灰尘已改为细碎、低对比、以反射变化为主；粗墙漆、分层白墙、波纹墙和吊顶的生成预设关闭灰尘，其他材质预设强度约 0.05–0.18，底色影响系数最多 0.01。原文中大片尘斑与 4%–12% 底色混合的建议已被此反馈取代。用户现自行调整 Inspector 参数，不再继续自动调参。当前参数说明见 `Assets/Game/Environment/ModernLab/README.md`，生成数据见 `surface_v2_report.json`。

## 当前问题与证据

检查来源：`Tools/build_materials.py` 与 `build_report.json`。

- 光滑白漆的实际粗糙度约 0.200–0.242，树脂地面约 0.154–0.205。缺少明显区别于清洁底材的薄灰尘、擦拭区和局部失光斑。
- 粗糙白漆约 0.843–0.921，但高度噪声幅度较小，缺少可在近景读出的砂粒、气孔、抹灰斑和施工方向。
- 当前噪声每个频段主要叠加三个正弦分量，部分颗粒还是规则点阵。直接提高强度会放大重复纹理，需重做噪声形态与分布。
- 白墙上方的水平砌块/分层接缝属于结构信息，需要单独的高度层，不能靠随机噪声替代。
- 现有彩色漆在整张 BaseColor 上乘颜色。若将灰尘直接烘进底色再染色，灰尘也会被染红、染绿。中性灰尘应在染色之后混合。

## 所有材质统一采用的层次

1. **结构层**：板缝、砖缝、竖向圆弧波纹、吊顶孔洞。尺度明确，保留模块拼接规律。
2. **底材层**：水泥砂粒、抹灰凹凸、喷漆橘皮、不锈钢细磨纹。不同材质使用不同形态和强度。
3. **使用层**：斑驳的薄灰尘、擦拭痕、细划痕、成簇污点，主要打散粗糙度与反射。
4. **稀疏损伤层**：少量磕碰、掉漆或小凹坑。按材质解释损伤，保持整体干净与颜色对比。

频率分三档：10–60 厘米的低对比不均匀区域；3–30 毫米的颗粒、孔洞、污点；约 0.3–2 毫米的微观细节。2 米范围的 2K 主贴图约为 1 毫米/像素，更小的颗粒由共享的细节法线与粗糙度响应承担，避免烘成单像素噪点。

## 薄灰尘的实现

- **坐标**：主遮罩使用模型 UV0。所有噪声在模型表面固定；不使用世界位置、世界高度、世界朝上方向来分配灰尘。
- **形态**：可平铺的分形噪声经低频扭曲后，形成疏密不同、边缘破碎的薄膜。再用有方向但不整齐的擦拭遮罩删去一部分。避免平均撒点。
- **颜色**：灰尘颜色的影响很轻，默认混合约 4%–12%；白墙只做轻微失光与脏白变化，不盖一层明显灰色。
- **粗糙度**：独立于颜色影响，可将部分光滑区域从约 0.22 推到 0.45–0.65，因此灰尘首先体现在灯条反射的破碎与模糊上。
- **法线**：薄灰只添加很弱的细粒或平滑原有微细纹理，不生成大块鼓包。
- **分布控制**：UV 中的板缝/凹槽遮罩控制少量积灰；需手工控制时使用可烘焙遮罩或物体顶点色。任意旋转模块后，这些痕迹仍保持在同一表面位置。
- **避免重复**：基础结构 UV 保持拼缝对齐。后续若需要每个模块不同的尘迹，只改变污渍层的局部 UV 偏移/种子，不随机移动整套板缝贴图。Unity 当前自动生成的第二套 UV 用于光照，不占用或覆盖它。

## 图 2 黑斑的实现与选择

建议默认：黑污点为主、小面积掉漆为辅。

| 类型 | 底色 | 法线/高度 | 粗糙度与金属度 |
| --- | --- | --- | --- |
| 黑色附着污物 | 深灰而非纯黑，不同点有轻微色差 | 很弱的附着感，或基本平坦 | 粗糙度升高；覆盖裸钢时金属度向 0 混合 |
| 漆面露底 | 露出基材颜色，不能把所有伤痕都涂黑 | 小凹边、破碎且不规则的漆膜边缘 | 漆膜为 0，金属基材区域为 1；裸露水泥仍为 0 |
| 小凹坑/点蚀 | 小暗心与边缘变化 | 可读但克制的凹陷 | 参数随基材变化，不统一变成金属点 |

生成方法：用稀疏的随机种子形成不等大的点团，经坐标扭曲和噪声侵蚀打破圆边；低频遮罩控制成簇出现与留白。默认污点占可见表面约 0.2%–0.8%，以 2–8 毫米点和少数 1–2 厘米破损为起点。一个遮罩同时关联颜色、粗糙度与高度；另保留损伤分类遮罩，避免把污物和掉漆混为同一种物理响应。

## 白色上墙的层次

在连续粗墙漆之外，增加白色横向砌块/分层墙变体：约 20–30 厘米高的横向层缝，局部错缝、很小的边缘高差和填缝凹陷。其上保留同一水泥颗粒。彩色墙裙使用相同底材纹理，色带边界由模块材质槽保持可编辑；白色区域的层缝可按参考独立配置。

## Blender → Unity 的共同实现

建议使用一套可复用的分层 Lit Shader Graph，并在 Blender 中对应同一套输入和遮罩。无需为每个材质新增工具。

- 保留现有 BaseColor / Normal / Mask 三张主贴图。
- Mask：R = 底材金属度，G = AO，B = 薄灰尘遮罩（目前空闲），A = 清洁底材 Smoothness。
- BaseColor 的 Alpha 可保存黑污点遮罩，RGB 保存中性底材；保持 Opaque，Alpha 不用于透明裁剪。掉漆等需独立分类的细节继续保留作者遮罩，并按最终着色需求烘入主图相应通道。
- 染色先作用于漆膜，再混入中性的污物与灰尘；裸露金属区域绕过漆膜染色。粗糙度和金属度使用相同覆盖遮罩混合。
- 细节法线按底材共享 2–3 张小贴图，不给 12 个材质分别复制一套。法线使用正确的法线混合，不把 RGB 简单相加。
- 保留颜色自由度，新增可调项：灰尘覆盖/色彩影响、灰尘粗糙度、污点强度、主法线强度、微表面尺度。它们是同一材质模板的参数。
- 若优先保留现有 URP Lit，可先把固定程度的粗糙度/法线变化烘入主图；中性灰尘与任意改色同时成立，则需要上述染色之后的混合顺序。

## 第一批验证顺序

先做三个小样，不一次覆盖全部成品：粗糙红/白水泥墙、带薄灰的光滑白/黄涂层、带黑污点与少量损伤的白漆金属。

1. 保存当前整套 Blender、Unity 材质与贴图版本。
2. 在实际模块上做近景对比，保留相同灯光、曝光、镜头与比例；增加低角度侧光和灯条反射观察位。
3. 约 0.5–1 米观察颗粒和小孔，2–3 米观察斑驳与表面差异；远处保持干净的色块关系。
4. 平移、旋转物体后检查污渍不漂移，检查拼接处没有明显贴图断缝或重复大斑。
5. Unity 中确认纹理色彩空间、法线方向、细节贴图 mipmap 和实际亮度；不要依靠抬高整体曝光来掩盖差异。
6. 小样确定后扩展至其余材质，沿用现有共享贴图和 36 个预制体的导出流程。

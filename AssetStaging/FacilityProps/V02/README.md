打开 FacilityProps_Review_v02.blend，场景下拉菜单有三个样板：金属箱、木箱、六种出口牌。Preview 为实际 Blender 渲染。

金属箱：保留现代款；苏联款橙色角柱、护盖、拉扣及把手固定件均换成黑铁。

木箱：ML_WoodCrate_1m 为浅色胶合板、松木框、金属护角和叉车脚；SV_WoodCrate_Old 为旧白漆拼板、裸木盖板、压条、黑铁护角与提手。两款木箱均不加文字。原点在底部中心。

出口牌恰好三类 × 两种设施，共六个主体：
- ML/SV_Exit_Side：墙装侧向牌，默认右箭头，附同主体可换的左箭头灯面材质。现代小人的朝向随箭头改变，文字不镜像。
- ML/SV_Exit_Ceiling：真实吊杆与安装盘，双面显示，上箭头表示向前；原点就是天花板安装面。
- ML/SV_Exit_Door：门楣安装支架，无箭头。

现代牌直接使用用户提供的 exit 小人.png，苏联牌仅 ВЫХОД 和对应箭头，完全没有小人。灯面图案为 1024×256 贴图；侧向左右通过材质切换，因此不增加主体种类。各灯面材质可分别调整发光。

Exports 中有 10 个 FBX：四个箱子、六个出口牌。模型仅一个 UV0，轮廓与部件是低模几何，文字和图标烘进贴图。木纹与黑铁为已烘好的 PBR 贴图，兼容现有 ModernLabLayered；材质映射与配置见 manifest.json，FBX 回导结果见 validation.json。

确认后再导入 Unity：按现代/苏联设施分别放回已有目录，复用现有涂层材质，增加黑铁、木材和灯面材质，并制作带合适碰撞与安装原点的预制体。当前只编辑 AssetStaging。

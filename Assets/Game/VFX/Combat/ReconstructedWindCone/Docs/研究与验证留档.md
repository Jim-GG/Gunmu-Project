## 可复用知识

1. **通道含义比颜色外观重要。** `Eff_Smoke_075` 是打包图，来源材质的 `_AlphaChannelMapping` 与 Shader 属性枚举确定 G 通道为此案例的遮罩，不能用 R 或 RGB 直接显示。噪声纹理为 `Eff_Noise_006`。两张按线性数据和 Repeat 导入。
2. **原始 UV 与动画 UV 分工。** 原 UV 用于轴向两端淡出；平铺、时间滚动和噪声扭曲只作用在采样 UV 上，避免两端淡出跟着滚动而闪烁。
3. **生命周期必须影响所有混合路径。** Shader 使用预乘透明，输出 RGB 已乘透明度；混合 `One / OneMinusSrcAlpha`。加法分量改变输出 alpha，RGB 仍受 `_LifeAlpha` 和 `_Opacity` 约束，防止结束后发光残留。
4. **朝向约定必须固定。** 根对象 +Z 是冲刺方向。原始 Mesh 做 X 镜像并反转三角绕序，UV 不重展。运行时通过 `Quaternion.LookRotation` 定向。
5. **兼容旧调用比另造入口更稳妥。** 适配预制体继续挂项目已有控制器，只把 `shells` 换成新三层风锥；可移植版本使用独立 `WindConeBurst`。两者共享同一个 Shader 生命周期参数。
6. **检测气流运动需要固定透明度。** `_PhaseOffset` 可在固定生命周期位置推进 UV 时间。这样能把“纹理真的流动”和“只淡入淡出”分开验证。
7. **预览第一帧可能是异步 Shader 编译空帧。** 验证只对本次局部渲染暂时关闭异步编译并预热，结束后恢复开关，不修改项目的长期渲染设置。

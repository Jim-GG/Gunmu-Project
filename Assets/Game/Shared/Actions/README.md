# 共用动作管线与拳套调参

入口为 **Tools → Game Actions → Animation Workbench 动画工作台**。原来的 Tools → Resonator 入口打开同一个窗口。窗口顶部的“拳套 / 共鸣者”切换配置；玩家 GauntletCombat Inspector 和 Action Set Inspector 也有打开按钮。

拳套配置为 `Assets/Game/Shared/Actions/Resources/GauntletActions.asset`。资源默认加载使已有场景中的拳套也能使用新管线；玩家预制体已显式引用。修改动作资产后保存即可，不需要重建关卡，也不要重新运行旧的场景搭建工具来调参。

## 当前操作

- 左键短按并松开：轻拳。轻拳从源动画第 10 帧切入，保留出拳之前的动作，缩短原片头重复前摇。
- 长按：原有三级 charge；32 / 62 / 92 帧档位、13 帧释放门槛和格挡能量跳帧保留。满蓄力只循环 charge full 的 0–50 帧。
- 出拳后摇可以接下一次左键或格挡，不必等整段动画结束。
- 左键预输入保存最近一次按下和松开，默认保留 **0.22 秒**。只有在这段时间内到达合法取消窗口才执行；不会把多次连点排成长队。提前松开的短按会继续作为短按，而不会变成长蓄力。
- 出拳时按住右键，在合法帧取消后摇进入格挡；松开右键立即取消防御状态并混合收起。
- 格挡中重新按左键可以进入攻击／蓄力。如果右键还按着，下一拳命中段结束后会恢复格挡。新按下右键则优先取消蓄力并格挡。
- Esc、失焦、禁用战斗输入或死亡会清除预输入、当前判定和吸附。未使用的格挡能量保留。

## 默认帧与吸附

所有帧数是源动画 **30 FPS** 的帧，不是游戏渲染帧。速度改变会同步改变这些窗口的实际发生时间。

| 动作 | 动作切入帧 | 有效帧（含首尾） | 可接下一次攻击／格挡 | 吸附上限 |
|---|---:|---:|---:|---:|
| punch1 | 10 | 14–17 | 18 | 0.65 m |
| punch2 | 0 | 2–5 | 8 | 0.85 m |
| punch3 | 0 | 4–8 | 11 | 1.00 m |
| punch4 | 0 | 6–11 | 14 | 1.15 m |

吸附移动的是玩家的 CharacterController，镜头不自动转向，也不把敌人拉过来。只在该动作的有效命中帧内、位移轨道同时有效时前进。默认选取前方半角 32°、3.1 米范围内的可见活目标，优先接近准星的目标；同一次攻击不在敌人间反复切换。没有目标、隔墙、目标死亡、超出角度或高差时不前冲。默认仅接地时吸附。

每段还受最大速度、接触间距、总位移预算和实际碰撞限制；够得着就少移，贴近就停，真正命中后停止额外前推。当前默认期望中心间距 1.05 米，最小间距 0.85 米。这里的距离是上限，不是每拳强制移动量，也不保证玩家偏离目标后仍然命中。

## 在同一工作台里修改

**动作页**：选择动作，调整起止帧、播放速度和默认混合；拖动时间轴查看姿态。攻击位移轨道中的起止帧、最大距离、速度、接触间距和累计进度曲线控制吸附爆发。玩家实际执行还必须满足有效命中帧条件。预览显示直线预算，运行时增加选敌和碰撞约束。

**命中盒**：可添加多段 Box / Sphere / Capsule，调整有效帧、大小、偏移、部位和伤害。黄色中心与彩色尺寸点可以拖动。默认 Root 是玩家的 View Pivot，盒体处于视线前方的真实世界空间；也可以绑定右手或自定义骨骼。相同命中组对同一个目标每次动作只造成一次伤害，不同目标分别计数；改用不同组可以制作多段命中。

**衔接页**：选择或添加 From → To，调整混合秒数、目标切入帧、来源取消开始／结束帧和预输入开始帧，再拖动过渡时间查看真正的混合姿态。取消帧 -1 表示等源动作结束；结束帧 -1 表示一直允许到源动作末尾。精确 From → To 优先于 Any Source；禁用精确规则后仍可能匹配启用的 Any 规则，需同时检查对应 Any 配置。

拳套通过 `charge` 接收下一次攻击输入，所以调整某一拳后摇时，修改 **punchN → charge**；调整回防时修改 **punchN → Parry-Start**。`charge` 到 `punchN` 的混合使用对应 Any → punchN，动作本身的起始帧决定默认切入点。格挡松开、格挡受击、蓄力释放属于玩法强制切换：使用配置的混合和切入帧，不等待输入取消门槛。

**事件页**：沿用共鸣者相同的逐帧事件。Signal 调用角色的 `onAnimationEvent` / `FrameEventReceived`；Sound 使用跟随插槽的 AudioSource 播放；Effect 可以调整偏移、旋转并选择 Follow Anchor。预览不执行声音、特效或伤害。蓄力跳帧不会补播被跳过的事件。

## 扩展新的角色或武器

创建 **Game Actions → Action Set**，指定预览模型，添加动作并引用 Motion Track（其中引用原始 AnimationClip），再配置过渡、命中盒、事件和位移。Sockets 可将 Head / RightHand 等语义映射到该模型自己的骨骼名称或层级路径；CustomBone 也可引用自建空物体插槽。不需要为每个新物体再写预览窗口。

运行时由输入或 AI 决定动作 ID，`ActionRunner` 负责按配置播放；`ActionMotionPlayer` 负责共用时钟与混合，`ActionHitbox` 负责同一套物理体积，`ActionContact` 负责玩家命中去重与伤害，`AttackMoveBudget` 共用位移预算。目标实现 `IActionTarget` 即可接受拳套和吸附选敌；共鸣者已经接入。

共鸣者保留原有 Tuning 资产、状态机和逐目标战斗规则，通过原组件的兼容层使用同一播放器、几何判定和事件执行器。旧资产的 GUID 和调参没有迁移重置。拳套当前保留原 Animator Controller 供旧预览使用，正式游戏由共用 Playables 管线驱动；调整正式播放速度请修改工作台中的 Speed，而不是旧 Controller 的 State Speed。

验证脚本与报告：`Docs/FirstPerson/Validation/`。现有第一人称、格挡训练说明中关于“整段出拳不可取消”“忽略攻击输入”和固定延迟伤害的描述，均由本文替代。

# 晶体冲击跑酷 V2：试玩与自己搭关卡

## 先试玩

打开 `Assets/Game/Scene/CrystalTraversalLab_V2.unity`，按 Play，点击 Game 画面。

旧版 `CrystalImpactParkour.unity` 保留；新版不再把晶体跑酷放在大范围上升风里。运行代码中的风力模型已升级，旧场景的旧风力数值不再代表 V2 的设置。

操作：WASD、Shift、Space；左键按住瞄准可交互晶体牵引，进入击打距离才开始两秒计时，松开后等真实命中帧反弹；R 回最近检查点；Esc 释放鼠标。

路线：

1. **筒仓 A / B**：从底部向上跳相邻平台。看绿灯和风量提示，开启时起跳；关闭时留在平台等待。空中用 WASD 调位置，上升风只减缓重力，不会自动把你送上去。A 出口沿桥进入 B，B 出口到风道。
2. **水平风道**：先过被侧面吸向大风扇的窄桥，再经过顺风和间歇逆风。朝目标走的同时修正横漂，逆风过强时等关闭窗口；在最前方风扇前向左转进晶体区。
3. **无风晶体区**：敲入口地面的蓝色裂缝，让晶体顶开门。过门走右侧短平台，敲右墙蓝色裂缝：对面墙上才会长出第一块可牵引大晶体。沿左右晶体交替反弹，中间可落脚休息，最终到高处出口。装饰用小晶体不是牵引目标。
4. **下降无人机**：到登乘边缘，等同一路线上轮流下降的无人机接近合适高度，跳上金属甲板，再跨到对面出口。它们会继续下去维修，不会水平送你过去。无人机下方回收后在顶部重新出现；玩家不会随之传送。

完成提示要求五项：经历风场、地面生晶、墙面生晶、至少一次晶体反弹、无人机借力。只是直接跑到终点不会跳过这些条件。

## 最快的搭建方法：拖 Prefab

目录 `Assets/Game/CrystalParkour/Prefabs/LevelModules`：

| Prefab | 用途 |
| --- | --- |
| `PulseSilo_A` / `PulseSilo_B` | 筒仓壳体、台阶、安全平台、间歇风、指示灯和检查点 |
| `FanDuct_ThreeDirections` | 侧向抽吸、顺风、逆风，含四叶旋转风扇和跌落复位 |
| `CrystalBay_NoWind` | 地面开门、墙面远程生晶、交替反弹、落脚晶体和检查点 |
| `DescendingDrone_SingleRoute` | 一架下降无人机及它自己的顶部 / 底部锚点 |
| `DescendingDrone_ThreeStream` | 三架错峰下降无人机、登乘平台与出口 |

也可以用 `GameObject → Crystal Parkour` 菜单，模块会生成在选中物体位置，没选中时使用 Scene 视图中心。

拖入之后先移动**整个模块根物体**，再展开改台阶、平台、敲击点、锚点。Prefab 支持普通 Unity 的 Overrides / Apply；想做独立版本就另存 Prefab Variant。新敌人、动画工作台和已有材质调参方式没有更换。

搭一套完全自己的布局时，可复制这些模块的子物体，随后重新连接下面列出的引用。不要再运行生成场景的菜单来覆盖手工关卡；构建菜单遇到现有同名场景会拒绝覆盖。

## 1. 调整风场

选中名字含 `Pulse updraft`、`Crosswind suction`、`Tailwind` 或 `Pulsed headwind` 的物体。

- **BoxCollider / Center、Size**：作用范围。它是 Trigger，不能当实体墙。`Shape = Cylinder` 时，X/Z 是直径，Y 是高度；`Box` 则是长方体。Scene 中有范围和方向箭头。
- **Gravity Relief / 剩余重力比例**：`0.42` 即仍有 42% 向下重力。最小限制 0.2；多个上升风重叠取最强减重效果，不会相加变成零重力。没有新增向上初速度，因此要先跳跃。
- **Horizontal Airflow / 最大水平漂移**：风给出的独立漂移速度，不覆盖 WASD。方向是风把人吹去的方向；抽吸风就朝风扇，推力风就离开风扇。勾“方向跟随模块旋转”后，旋转整个模块即可改变方向。
- **漂移加速度**：多快逐渐被带走。先调小加速度，可以给玩家更多反应时间；不要只把最大速度调得特别大。
- **间歇开关**：开启秒数、关闭秒数、相位偏移、开关渐变。Inspector 底部可以输入预览关卡时间，看那一秒的风量。
- **进入 / 离开混合秒**：出入边界的平滑时间。

当前筒仓开启 5 秒、关闭 2.5 秒，第二个错开 2 秒；逆风开启 4 秒、关闭 3 秒。每个台阶高差 1.6 米。基础跳跃高度 1.1 米，风开时实测约 2.67 米，因此这些台阶需要利用开启窗口。

玩家的 `FirstPersonMotor` 中 `Air Speed = 5.2`、`Air Acceleration = 18` 控制空中 WASD。`CrystalTraversal` 开启时才启用这套空气操控；未挂跑酷组件的玩家默认仍使用原移动设置。冲击反弹的动量另行保留。

**布置时的经验**：风道两头放足够大的安全平台，危险风区做窄桥；在迎风风扇前留等待点和侧向出口。把晶体区放在所有 WindVolume 范围外，否则又会出现两套机制争夺节奏。

## 2. 摆放可牵引晶体

装饰资源在 `Assets/Game/Environment/crystal/Prefabs/V2`。共 12 类：内角、墙地接缝、天花垂挂、混合墙晶、地面簇、三株小簇、五株小簇、大型针片混合簇、壁面片晶脉、侧向锚点、天花晶帘、可站立台面。

**装饰 Prefab 本身没有玩法组件。** 最快是从 `CrystalBay_NoWind` 复制一个 `Anchor`，它已经连好模型、真实网格碰撞和 `CrystalSurface`。

自己组一个：

1. 创建空根物体，放在墙上的生长位置。
2. 把侧向晶体 Prefab 作为它的子物体；保持 Prefab 内 `Authored FBX axes` 的校正旋转。**不要清空内部 FBX 物体的旋转**。外面的根物体可以正常旋转、缩放。
3. 模型的 MeshFilter 所在物体上添加 MeshCollider，填同一个网格；静态晶体不勾 Convex。
4. 根物体添加 `CrystalSurface`，把 MeshCollider 拖进 Contact。勾 Can Tether。
5. 当前侧向资源局部 **+Z 向房间内部生长**；旋转外部根物体，让蓝色 Z 箭头朝房间。

`Use Launch Normal` 可指定稳定的弹出方向：勾上后用根物体局部 `Launch Normal`，当前墙晶是 `(0,0,1)`。不勾就采用实际命中晶面法线。`Normal Launch Speed` 为离墙速度、`Upward Launch Speed` 为向上速度，`Tangential Retention` 为入射时的切向动量保留。

墙晶当前离墙速度 7.2、向上速度 8.2。玩家 `CrystalTraversal` 的 `Maximum Pull Distance` 为 12 米；摆放时按**实际可见尖端和玩家视点之间**的距离留余量，不能只看两个根物体的距离。让前一块发射后能看见下一块，且中间没有普通墙 / 平台挡住射线。牵引途中不耗两秒，但仍会因路径堵塞或拉太久取消。

可站立晶体继续用简单 BoxCollider 覆盖平坦台面，避免脚在小尖晶上抖动。换成纯装饰物时移除 `CrystalSurface` 和不必要的碰撞即可。

## 3. 自己做“敲这里、别处生晶”

参考 `Strike wall / grow opposite side anchor`：

1. 复制敲击根物体到玩家走得到、拳套够得着的位置。它的 BoxCollider 就是敲击判定区，蓝色板是视觉提示。
2. 选 `CrystalGrowthSite`，点 **选择生长目标**，移动这个子物体到想生长的墙上，甚至远到对面墙。只移动生长目标，不要连敲击根物体一起移。
3. `Growth Root` 引用整个生长物；`Strike Collider` 引用敲击范围。目标可以是含 `CrystalSurface` 的锚点，也可以是站立台面或多个晶体组成的组。
4. `Duration` 为生长时长，`Emergence Distance` 为从墙内冒出的距离；`Growth Direction` 使用**敲击根物体局部坐标**。本例根物体的 Y 已朝离墙方向，所以 `(0,1,0)` 即向墙外生长。
5. `Wall Growth` 决定 HUD 的墙面 / 地面完成项。它不负责决定形状。

编辑模式显示最终目标以方便摆放。运行时 Awake 会先隐藏，拳套在有效命中帧打中敲击范围后才显现；动画前摇不会触发。生长中关闭碰撞和牵引，结束后打开。

要继续顶开卷帘门：给门加 `ParkourGate`，把对应 Site 拖进 Required Site，调 Open Height / Speed。门会在该 Site 生长完成后上移。目标根物体可以同时放门边晶体和远程锚点，让一次敲击触发一组生长。

## 4. 自己做下降无人机队列

拖 `DescendingDrone_SingleRoute`，展开会看到 `Top / spawn`、`Bottom / repair destination`、无人机本体。这两个锚点与无人机**同级**，不应放进移动的无人机本体内。

选无人机上的 `TraversalDrone`：

- Route 选 `Descending Stream`。
- Start / End Anchor 分别指定顶部、底部。要纯垂直，就让两个锚点 X/Z 相同。
- Speed 是米 / 秒；Respawn Seconds 是到底部隐藏回收的秒数。
- 周期 = 两锚点距离 ÷ Speed + Respawn Seconds。
- 做三架：复制整条路线三次，相位分别设 `0`、周期的 `1/3`、周期的 `2/3`。本关 14 米、1.4 m/s、回收 2 秒，周期 12 秒，相位 0 / 4 / 8。

选中组件时 Scene 中有路线和起终点移动手柄。移动整个路线容器会连同锚点一起移，不会留下世界坐标的旧路线。Deck 必须拖承重甲板的 BoxCollider，别拖装饰容器。隐藏回收时不会携带乘客瞬移。

## 5. 风扇、检查点与跌落复位

风扇 `Rotor / four dark panel blades` 上 `WindFanRotor` 可改 Degrees Per Second，负数反转。四片叶使用现有 `Lab_Dark_Panel` 材质；风扇持续旋转，风量的开关由 WindVolume 单独控制。风扇视觉转动不等于始终有力。

复制任一 checkpoint；调整 Trigger 大小，把 `Respawn feet` 放在安全平台上方约 0.1 米，旋转它决定复位朝向。Finish 勾上则检查完成条件。复制跌落复位体 `ParkourResetVolume` 到坑底，改 BoxCollider 范围即可；它没有实体碰撞。

## 6. 在 Blender 中继续改晶体

作者文件：`ArtSource/Crystal/V2/Crystal_Environmental_GeometryNodes.blend`，不是 Unity Assets 内的源文件。原版和开始这次改动前的副本都保留。

打开 `Environmental Crystal Kit V2` 场景，选择集合 `crystal · environmental geometry nodes` 中任一对象，在修改器里调整：

- Seed：换随机分布。
- Density / Small Detail Density：主晶与根部微小晶体密度。
- Minimum / Maximum Scale：尺寸区间；Tilt：相对表面法线的偏转。
- Hero Scale / Direction：主轮廓晶体的尺寸和方向。
- Hero Points：隐藏的引导点物体，编辑其顶点可精确摆主晶位置。
- Platform Core：站立台面用的额外晶体核心。
- Show Root Bed：可选的埋入表面的背衬，默认关闭，以免出现整齐的矩形基板。

这些对象保留真正的 Geometry Nodes 修改器，没有只留下已应用的死网格。种子库同时有细针、斜针、宽片、薄片、粗尖和断根。

导出自己新增的变体：复制要导出的对象，把复制品 Location 清零（展台里的摆放坐标不应带进模型），只选复制品，导出 FBX，勾 Selected Objects / Apply Modifiers，Forward `-Z`、Up `Y`，不导出相机 / 灯光。放进 `Assets/Game/Environment/crystal/Models/V2`。导入 Unity 后保留 FBX 内部轴向校正，在外面加零旋转空根做 Prefab；材质复用 crystal/Materials 的三种 Facets，不要生成一堆新材质。做完删除临时复制品即可，原可编辑 GN 对象保留。

批量生成脚本 `ArtSource/Crystal/V2/Tools/build_environment_nodes.py` 是作者资产配方，会重建这 12 个固定型号，手工改过源文件后不要直接运行它覆盖修改。

## 已验证与仍需你试玩的部分

Unity 原生检查已覆盖：两秒计时和真实命中后反弹、两类生晶、风中 WASD、重叠风不抵消全部重力、间歇关闭、全部相邻筒仓台阶可跳、晶体与风区不重叠、三机下降与甲板携带、回收不瞬移、真实壁晶网格可牵引和击打。Play Mode 还确认拳套骨骼动画、风扇旋转、空中横移正常，记录期间无运行错误。

这是一套供你调整路线节奏的原型；上述自动检查不等于完成了人工从头到尾的通关与手感评审。尤其水平风抵消的力度、无人机登乘时机和晶体链的瞄准节奏，请按自己的设计继续调。

验证记录在 `Docs/CrystalParkour/V2/Validation`，截图在相邻 `Preview` 目录。

# 原版拳套与关卡解谜整合

正式关卡继续使用 levels 的地图、移动和动量解谜；拳套改用 UDK7M-BOSS-FIGHT 分支完整的 `GauntletCombat`，同时保留关卡中较长的冲刺距离和风锥。

## 拳套只有一个状态机

`PlayerChargedPunch` 现在是关卡兼容接口：转发鼠标输入、晶体补能和物理机关接口，不再射线结算伤害，也不再计算另一套蓄力时长。

蓄力、轻攻击、输入缓冲、取消窗口、混合过渡和逐帧 Hitbox 均来自原版 `GauntletActions`。默认 30 FPS，以原版的 32 / 62 / 92 帧为蓄力档位，轻攻击与延迟释放规则也沿用原版。三格能量按原版规则跳过三个蓄力区间。

`PlayerGauntletView` 只创建模型和配置相机动作。旧 Animator 状态机不再与原版 Playable 动画图同时驱动骨骼。身体冲刺碰到目标只终止位移，实际伤害仍等待动画 Hitbox 的有效帧。

## 解谜与冲刺

- 保留关卡的一至三级冲刺参数（默认 2.5 / 4.5 / 6.5 米），关闭叠加的 BOSS 短距接敌辅助，避免两套位移重复作用。
- 冲刺保留风锥；轻攻击不触发虚假的冲刺位移。
- 动能方块仍按六轴接受冲量、封存和累积速率、释放动量；物理作用从原版 Hitbox 的接触回调触发。
- 晶体直接向 `GauntletCombat.BlockEnergy` 补满三格，与格挡获得的能量完全共用。
- 保留晶体冷却、机关按钮、开关门禁、子弹时间与关卡切换。地图尺寸、布局、出生点和教学内容不在本轮重做。
- 教学共鸣者继续保留蓄力击飞规则，普通敌人的伤害与击飞使用原版动作数据。

## 格挡

完美格挡沿用原版 `ParryStart` 窗口，伤害为零；非完美格挡承受 34% 伤害，即减伤 66%。生命内部使用浮点数，例如 30 点攻击在非完美格挡后扣 10.2 点，避免整数取整改变减伤比例。背后和不可格挡攻击不受正面格挡保护。

## 音画反馈与可调参数

关卡复用原版三段蓄力录音、满蓄力循环、能量流、满充闪光、材质命中、脚步和落地音库。录音位置直接读取原版蓄力时钟；子弹时间下同步播放速度。取消和暂停会停止或暂停相应声音。

`LevelFeedback.asset` 配置关卡提示音和尺寸；`GauntletImpactVFX.asset`、`SurfaceSounds.asset`、`AdvancedCombatVFX.asset` 继续提供共享资源。旧临时火花和冲击圈不再叠加到关卡出拳上。

风锥过亮的原因是 `WindConeBurst` 每帧用组件的 1.7 覆盖材质已调整的 0.1 / 0.167。现在默认尊重每个材质的 `_Intensity` 与 `_TintColor`；需要组件覆盖时，显式启用 `overrideMaterialAppearance`。动态透明度与生命周期仍由脚本管理。

## 色散、扭曲与热浪接入

此前高级效果主要用于 BOSS 晶柱碎裂和最终爆炸，拳套的日常玩法没有调用，持续热浪资源也没有使用。现在 `GauntletCombat` 初始化时自动接入 `GauntletAdvancedPresentation`，UDK7M 场内原版玩家与关卡玩家使用相同的事件入口。

| 触发 | 实际效果 |
| --- | --- |
| 蓄力达到完整时长的 65% | 拳套锚点处持续热浪；取消、松手出拳、暂停或禁用后停止 |
| 二级/三级蓄力拳实际 Hitbox 接触 | 命中点短暂色散与画面扭曲；三级同时产生冲击热浪 |
| 完美格挡 | 视线前方短促色散波；非完美格挡不触发此提示 |
| 关卡晶体补能、动量释放 | 物体处较轻的色散波纹 |

重拳反馈必须等待有效帧的真实接触，同一拳只播放一次。效果不增加碰撞体，也不修改伤害、蓄力时长或冲刺距离。相机启用 Scene Color 所需的颜色纹理，持续热浪实例复用，瞬时效果走共享对象池。

在 `Assets/Game/Shared/Actions/Resources/LevelFeedback.asset` 的“玩法中的色散与热浪”中可开关整组效果，调整开始时机、范围、扭曲像素、色散像素与热浪透明度。

本轮最终画面验证在 `Assets/Game/Scene/UDK7MBossArena_ThreePhase.unity` 的临时副本中执行，使用场内原版玩家和共鸣者，保留用户场景编辑。报告为 `screen-effects-validation.json`，开启/关闭效果的同机位图片位于 `AssetStaging/ScreenEffectsIntegration/`。暂停画面用于稳定对照，不代替用户对连续运动手感的判断。

UDK7M 专项 21 项通过：实际相机的热浪、完美格挡色散、共鸣者重拳命中均有可见像素变化；验证了真实伤害、命中前不播放、同拳不重复、低段不显示、暂停/恢复及取消停止。

## 验证和本地编辑

隔离项目验证原版 Hitbox 有效帧、无按键即时伤害、统一能量池、完美/非完美格挡、风锥材质设置、方块物理、完整关卡衔接和 BOSS 三阶段回归。流程冒烟会放开出口门禁，仅验证衔接，不代替人工逐关解谜通关或主观试听。

用户已有的 BOSS 场景修改、期间的第一关编辑、独立拳套模型与 Blender 源文件均保留；本次代码提交不纳入这些并行编辑。关卡重置和扩充留待本轮整合之后。

最终验证：原版拳套专项 26 项、完整关卡流程 32 项、BOSS 回归 45 项全部通过；15 个构建场景无丢失脚本或断开的对象引用。验证在隔离项目中执行，源文件哈希见 `authored-combat-integration.json`。

# 现代设施第一关：卸货大厅

场景：Assets/Scenes/现代设施/Modern_01_UnloadingHall.unity

当前打包流程从苏联实验室进入卸货大厅，再依次进入冷却井与巡逻竖井。三关可分别在 Unity 中打开试玩。

## 试玩顺序
1. 开局已有拳套。第一架无人机从高处接近，红灯和短音预告射击。右键面向无人机格挡充能，左键蓄力松开出拳。
2. 将无人机击向侧墙。生命值沿用 Resonator_Default（当前120），零/一/二/三档伤害为24/40/65/110，与现有共鸣者接收器一致。击飞状态撞实体墙立即损坏；正常飞行、蹭地不算撞墙击毁。耗尽血量也可损坏。
3. 准心对准残骸，5米内按E接管。若残骸难以接近，在出生点左侧维修座3米内按E回收接管。
4. 鼠标指方向，按住右键飞行，松开悬停；20秒从接管开始计算。飞到左前方高处控制室，靠近控制台（2米内）按E接入，打开中央隔断。其他位置按E返回；超时也会返回。首次机关未完成时残骸回维修座，方便重试。暂停不扣时间。
5. 穿过隔断后出现两架无人机。全部损坏后中间出口门打开，走到出口进入冷却井。
6. R重开会还原玩家出生点、敌人及机关。死亡后也可按R；关卡完成后用“重新试玩本关”。

## 空间和编辑
40×72米、净高约12米，包含前厅、悬空控制室、后厅、出口短廊。
Hierarchy分为建筑结构、工业陈设、无人机与流程。货箱保留为掩体；采用亮银金属墙面、深银抛光金属地面、石墨灰门板和少量紫色标识，已删减配电柜、货架、泵组和法兰管线。环境采用纯色URP光滑材质，并使用预先捕获的大厅环境反射（不依赖项目已关闭的实时反射）。墙面金属度0.92、光滑度0.94；地板金属度0.96、光滑度0.98。
无人机与现代实验室模块使用Game库素材，紫晶保留原有补给功能，玩家使用现有Player预制体与拳套。
修改地图时可移动serviceDock、remoteSocket、secondWaveTrigger、exitPoint等命名锚点，不需要修改脚本坐标。无人机高度通过实例位置调整，approachSpeed、attackWindup、attackInterval、detectionRange均可调；遥控时长和速度在CargoDroneLesson上修改。
CargoHallBuilder是生成器，场景生成后可手工微调；不要对手改后的场景重复执行生成菜单，否则将重建该场景。

## 验证及边界
在测试副本中进行Unity批处理Play Mode验证：组件引用、共鸣者同血量、拳套可见、墙体遮挡、拳套击飞实际碰撞、接管输入交接、暂停计时、超时恢复、遥控入口、终端开门、第二波激活、清场门禁、步行到出口。并检查第一人称与俯视渲染画面。
自动验证不替代手工手感测试：需要玩家重点试格挡窗口、镜头灵敏度、无人机下降速度。音效为可替换的合成占位音。
导航是当前大厅使用的直线接近加碰撞避阻，尚无复杂飞行绕路寻路；失去视线即停止攻击。若加大量迷宫式障碍，需要另补空中导航。

无人机现在会平滑转向玩家头部高度，headLocalDirection 控制模型头部的本地轴，turnSpeed 控制转向速度。击飞和残骸状态不会继续追踪朝向。
## 冷却井与巡逻竖井

冷却井（Modern_02_Cooling）沿加长的走廊到达升降点，使用斜板反弹货箱打开门禁，再搭第二架无人机上层离开。

巡逻竖井（Modern_Combat）有八级平台。只需对付当前层的无人机。击毁后回到紫色登乘标记按 E，掉落时回到当前层。最后一架无人机会在风扇前等候，按 Q 开启子弹时间，叶片减速后会自动载人穿行。到晶石房走上紫色平台完成关卡。

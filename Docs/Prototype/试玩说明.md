# 零界核心玩法 Demo 试玩说明

版本 V0.1；2026-10-30；Windows 64 位。
本次是单房间机制原型，用占位模型验证格挡、储能与反击，不包含完整剧情流程。

## 启动
完整解压 ZIP，双击 WindowsDemo 内的“棍木项目.exe”。不要运行 UnityCrashHandler64.exe。exe、_Data 文件夹、UnityPlayer.dll、MonoBleedingEdge、D3D12 保持相对位置，不要只发送 exe。

## 操作
| 输入 | 行为 |
|---|---|
| WASD / 鼠标 / Space | 移动 / 观察 / 跳跃 |
| 按住右键 | 格挡正面攻击，每次成功格挡获得一格储能 |
| 左键 | 无储能时普通出拳；有储能时消耗一格释放冲击 |
| Esc / 点击画面 | 释放鼠标 / 恢复控制；Esc 不会暂停敌人 |
| 胜利或失败后 R / Retry 按钮 | 重开本轮 |
| Alt + F4 | 退出程序 |

## 试玩流程
观察敌人靠近及攻击预告，分别尝试挨打、后退躲避、正面格挡。格挡后松开右键保留储能，再用左键释放反击。击败敌人后按 R 重试。再不防御直到失败，用 Retry 按钮重试。

## 已知限制
一个占位敌人，临时英文 UI，无正式拳套手臂、音效、出拳和机械压缩动画。敌人直线靠近，不会绕墙。尚无独立奔跑、完整追逐、电梯演出和谜题。
格挡覆盖正面水平 120 度；出拳冷却期间不能格挡。攻击打空也消耗储能。击败后隐藏敌人，非致命冲击才能观察击退。
场地没有完整围墙和掉落复位，请在中央试玩；走出地面掉落后需关闭程序重新启动。

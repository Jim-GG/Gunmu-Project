## 当前可玩的内容

当前实验室场景：Assets/labdemo.unity。
流程：靠近终端按 E → 调整滑条进入绿区并稳定 → 确认校准 → 到支架按 E 拾取拳套 → 敌人启动 → 格挡储能并反击 → 敌人被击败后打开出口 → 玩家走过出口触发完成 → R 或按钮重试。

进入场景时没有拳套攻击与格挡能力，敌人不会提前行动。解谜成功只解锁拾取条件，不直接发放装备或启动敌人。拾取后才开启战斗。击败敌人不会立即结束整段 Demo，必须走到出口。

场景目前使用方块、胶囊和临时英文 UI，功能演示优先；没有正式角色、拳套模型、压杆动作、正式音效及成品美术。

## 操作

| 按键 | 行为 |
|---|---|
| WASD / 鼠标 / Space | 移动 / 观察 / 跳跃 |
| E | 对准近处终端或拾取物进行交互 |
| 面板中拖动滑条 / Confirm | 校准 / 确认 |
| 面板中 Esc 或 Close | 关闭面板，恢复操作 |
| 拳套拾取后按住右键 | 正面格挡 |
| 拳套拾取后左键 | 无储能普通拳；有储能消耗一格释放冲击 |
| 胜利或失败后 R / 重试按钮 | 重新加载已保存的场景，重置流程 |
| 非面板状态 Esc / 点击画面 | 释放鼠标 / 恢复控制 |

解谜面板会暂停玩家移动、视角和出拳，关闭后恢复进入前的组件启用状态。面板并非全局暂停系统。校准完成前关闭面板，旋钮位置保留，但连续稳定计时重新累计。

## 参数基线

以下为当前代码默认值；已保存场景和 Inspector 实际配置具有优先级。程序里的字段名方便查找，数值仍需策划试玩调整。

| 分类 | 字段 | 值与单位 |
|---|---|---|
| 视角 | mouseSensitivity / pitchLimit | 0.1 度/输入单位；上下各 85 度 |
| 移动 | moveSpeed / jumpHeight / gravity | 5 米/秒；1.2 米；20 米/秒² |
| 玩家 | maxHealth / invulnerabilityDuration | 5 点；0.8 秒 |
| 交互 | interactionRange | 2.8 米 |
| 校准 | initialDialAngle / targetAngle | 60 度 / 240 度 |
| 校准 | tolerance / requiredStableTime | ±15 度 / 0.8 秒；稳定后还需点击确认 |
| 拳套 | punchRange / punchCooldown | 2.5 米 / 0.45 秒 |
| 拳套 | punchDamage / chargedDamage | 1 点 / 2 点 |
| 拳套 | maxStoredImpulse / guardAngle | 3 格 / 正面水平总角度 120 度 |
| 拳套 | chargedKnockbackSpeed | 7 米/秒 |
| 敌人 | maxHealth | 3 点 |
| 敌人攻击 | attackRange / windupDuration | 2.2 米 / 1 秒 |
| 敌人攻击 | recoveryDuration / attackDamage | 1.5 秒 / 1 点 |
| 敌人运动 | chaseSpeed / stopDistance / detectionRange | 2.5 / 1.7 / 12，单位分别为米/秒、米、米 |
| 击退 | deceleration | 14 米/秒² |

规则：松开格挡保留储能；储能攻击打空仍消耗一格；出拳冷却期间不能格挡；普通拳不击退；非致命储能反击使敌人后退并打断攻击。当前没有独立奔跑、耐力、手动压杆操作与过热系统。

策划原关卡方案的走廊追逐数值为步行 3、奔跑 5.2—5.5、追逐者 3.6—3.8 米/秒。这组数值尚未用于当前战斗原型，不要与当前玩家 5、敌人靠近 2.5 混为一组已定平衡。

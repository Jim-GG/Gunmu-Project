# 六关串联、通关通道与围封（2026-11-04）

## 本轮范围

1. 第一关 → 第二关 → 第三关 → 第四关 → 第五关 → 第六关，全部走通。
2. 每关解谜成功后出现“通道已开启”，走入光柱触发黑场转场并加载下一关。
3. 第三至第六关补齐围封：Plane 地面 + Cube 围墙，保留原机关与装饰。
4. 第六关通道走完后显示“全部关卡完成”界面。
5. 教学关 → 第一关的原有入口保持原样；本轮不额外加转场。

## 玩家流程

- 第一、二关沿用原有出口门/通道：解谜成功、门升起后，出口触发区进入共享转场。
- 第三至第六关：机关触发后 0.55 秒出现通道，走入光柱前的触发区进入下一关。
- 第六关：走入光柱后黑场，显示完成界面，可重新游玩或返回主菜单。
- R 重置本关时，通道会随机关一起关闭；再解谜会重新出现。

## 新增脚本与资源

- `Assets/Scripts/LevelFlow.cs`：常驻流程管理器，负责六关顺序、黑场淡出/淡入、最后一关交接。
- `Assets/Scripts/LevelPortal.cs`：通道表现与触发。包含传送环、光柱、悬浮菱形、屏幕光标/距离、通道提示。
- `Assets/Editor/LevelFlowInstaller.cs`：一键安装/更新六个通道与围封，更新构建列表。
- `Assets/Editor/LevelFlowVerify.cs`：编辑模式校验菜单与批处理入口。
- `Assets/Resources/DemoPresentation/PortalBeam.mat`：光柱专用透明材质，避免打包时 Shader 被裁剪。

## 表现与提示

- 通道：地面双层发光环 + 半透明光柱 + 悬浮菱形光标 + 点光源。
- 屏幕提示：
  - 开启时顶部显示“通道已开启”，持续约 4 秒。
  - 持续显示屏幕光标/距离；光标离开视野时贴边显示。
  - 距离 7 米内显示“走入光柱，进入第 N 关”。
  - 光标靠近屏幕底部时，距离标签自动改到光标上方，避免压住底部充能条。
  - 左上角任务文本同步改为“通道已开启”。
- 转场：0.45 秒黑场淡出，加载后 0.55 秒淡入；转场期间冻结世界并屏蔽移动/视角输入。

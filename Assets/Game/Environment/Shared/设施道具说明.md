# 设施箱子与出口牌

现代设施：`Assets/Game/Environment/ModernLab/Prefabs/Props`。
苏联设施：`Assets/Game/Environment/SovietFacility/Prefabs/Props`。

每套有金属箱、木箱，以及 Side / Ceiling / Door 三款出口牌。苏联牌使用「ВЫХОД」，没有小人；现代牌使用你提供的小人图案。

Side 的 Inspector `Exit Sign Direction > Direction` 可选 Left / Right。Ceiling 是双面牌，箭头朝上表示前行，根位置在天花板安装面。Door 不带箭头。Side 与 Door 是贴墙的单面牌，背面为安装结构；需要旋转根物体，让带字的一面朝向玩家。

预览场景：`Assets/Game/Scene/FacilityPropsReview.unity`。道具带基础 BoxCollider，均可直接拖入场景；新材质独立创建，继续复用已有 ModernLabLayered 微表面材质管线。

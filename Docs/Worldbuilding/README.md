# 《零界》世界观设定档案 V0.9

建议首先打开“零界-世界观设定档案.html”：有目录、状态标签，图片全部嵌入，离线可读。
“零界-世界观设定档案.pdf”用于固定版式阅读。
“零界-世界观设定档案.md”用于继续修改正文，图片放在 images/。

整理范围：ChatGPT《构思巨型秘密设施》当前工具返回的末尾五轮与末版总纲，不是整条聊天完整导出。更早正文与附件未取回。
状态：已定 / 沿用待核 / 本次建议 / 留白。年份、专名、角色身份与图像的确认程度以正文标记为准。

文件：
- 图文档案：HTML、PDF、Markdown。
- images/：两张 imagegen 概念图，三张可编辑 SVG 图表，以及各图 Mermaid 源码。
- sources/聊天记录-可访问五轮.md：可访问原始用户与 ChatGPT 文字，按从旧到新保存。
- 图像生成与设计说明.md：完整提示词与新增视觉内容说明。
- 图表源码.mmd：人物关系图源码；时间线与空间拓扑源见 images/。
- build-archive.mjs：从 Markdown 与图片重建 HTML / SVG；使用本机 bundled runtime 的 marked。
- render-and-check.mjs：本机 HTML 渲染、布局检查与 PDF 导出脚本。
- qa/：工作目录中的版面复核图与检查报告，不纳入轻量交付压缩包。

创建于 2026-10-29（Asia/Hong_Kong）。所有文件均存于 Unity 项目的 Docs/Worldbuilding/，未修改 Assets/ 或游戏代码。
